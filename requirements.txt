# WICHTIGE HINWEISE

#
# 1. PaddleOCR + LangChain 1.0 Kompatibilität:
#    - Nutze: from langchain_community.docstore.document import Document
#    - NICHT: from langchain.docstore.document import Document
#
# 2. NumPy Version:
#    - Einige Packages (PaddleOCR, PaddlePaddle) unterstützen NumPy 2.0 noch nicht
#    - Daher: numpy>=1.26.4,<2.0.0
#
# 3. GPU Support:
#    - Für CUDA 12.x: torch mit --index-url https://download.pytorch.org/whl/cu121
#    - Für CUDA 11.8: torch mit --index-url https://download.pytorch.org/whl/cu118
#    - Für CPU-only: Aktuelle Version ist OK
#
# 4. Pillow-SIMD (Optional, +30% Speed):
#    - Erfordert Build-Dependencies: sudo apt install libjpeg-dev zlib1g-dev
#    - pip uninstall Pillow && pip install Pillow-SIMD
#
# 5. Installation Order (empfohlen):
#    1. PyTorch + CUDA (falls GPU)
#    2. pip install -r requirements.txt
#    3. Teste Kompatibilität: python -c "import paddleocr, langchain"
